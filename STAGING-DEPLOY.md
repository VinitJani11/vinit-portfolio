# Staging deployment: portfolio-v7-preview

This staging copy has adjusted Open Graph URLs and `noindex, nofollow` metadata. Google may still discover the URL; do not put secrets or confidential material on a public Pages site.

1. Create a new **public** GitHub repository named `portfolio-v7-preview` under `VinitJani11` (do not use the existing `portfolio` repository).
2. Open the new repository, choose **Add file > Upload files**. Drag **all the files and the `assets` folder inside this folder** to the uploader. Do not upload the ZIP by itself and do not put `index.html` in a nested folder. Commit to `main`.
3. Navigate to **Settings > Pages > Build and deployment**. Select **Deploy from a branch**, branch **main**, folder **/(root)**, and **Save**.
4. Click **Visit site** in Pages settings or visit https://vinitjani11.github.io/portfolio-v7-preview/ after the deployment finishes.
5. Test on desktop and phone: light/dark toggle, rotating roles, page anchors, filters, all six image galleries (buttons, swipes, Escape), experience accordions, the CV print view, all project links and the contact buttons.
6. Confirm employment facts and remove any sensitive screenshots before sharing widely.

## After approval

Back up the existing `portfolio` repository (tag or separate branch) and upload the original V7 audited files, **not this staging folder**, to the existing repository's Pages publishing root. The original V7 contains production social URLs.
